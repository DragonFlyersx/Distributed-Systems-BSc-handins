
# The Chitty-Chat server

This is a project for handin-3 in Distributed systems.
This service creates chat service for multiple people to talk to eachother


## Hosting

To start the server you will need to run the server on the pc you wish to host

```bash
  go run Server.go
```


## Joining

To join a server change the Ip address the chosen server in the code. else it will connect to the localhost:5051

To run the client use

```bash
  go run Client.go
```
